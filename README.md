StockFlow NG

StockFlow NG is a modern multi-shop business platform designed to help businesses manage inventory, process sales, connect with customers, and promote products efficiently.

Core Features
Multi-shop management system
Inventory tracking and stock updates
Sales and transaction processing
QR-powered shop identity and networking
Follow/connect business ecosystem
Flyer generation and marketing tools
Product discovery and social features
Responsive web and mobile-friendly design

Built with:

Next.js App Router
TypeScript
React
Modern API architecture
